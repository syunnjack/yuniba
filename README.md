# YUNIBA

業界のリアルな課題から生まれた220件のAI業務システムを、検索・設計・進捗管理できるデータ駆動型ポータルです。

## 機能

- 220件のシステムを業界・目的・ツールで絞り込み
- 課題、AI活用方法、期待効果をまとめた個別設計画面
- Claude Codeなどへ渡せる実装用設計図のコピー
- 220件すべてを共通実行エンジンへ接続
- 入力からローカル成果物を生成し、コピー・Markdown保存
- CSV・JSON・TXTを読み込み、複数レコードを一括処理
- システムごとの実行履歴を端末内に保存
- お気に入りと実装進捗をブラウザに保存

## 機密運用

このリポジトリは部外秘データを含むため、公開デプロイを無効化しています。実行データと履歴はブラウザの `localStorage` にのみ保存され、外部サービスへ自動送信しません。外部連携が必要なシステムも、接続設定を行うまではローカル成果物の生成だけを実行します。

## 開発

```bash
npm install
npm run dev
```

品質確認は `npm test`、`npm run lint`、`npm run build` で行います。

## データ再生成

掲示板のエクスポートテキストから全システムを再生成できます。

```bash
npm run generate -- /path/to/pasted-text.txt
```

生成件数が220件でない場合は失敗するため、欠落を検知できます。
